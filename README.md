# Caviar · Посты и сторис для соцсетей

Страница для менеджеров: готовые посты и сторис Caviar в полном разрешении — скачать по одному или всей коллекцией архивом.

- Новые коллекции — сверху (по полю «Дата выкладки» карточки в Notion).
- Фильтр: всё / только посты / только сторис.
- Тумблер языка: русская и английская версии.
- Клик по превью — просмотр в полный размер, стрелки ← → листают.

## Структура

```
index.html                 страница (стили и скрипты внутри, шрифт Nunito Sans)
data/<slug>.json           описание коллекции: название, дата, ссылка на карточку Notion, список изображений
data/content.js            сборка всех коллекций для страницы (генерируется)
assets/<slug>/<posts|stories>/<ru|en>/NN.jpg   полноразмерный файл для скачивания
assets/<slug>/<posts|stories>/<ru|en>/NN.webp  превью для сетки
tools/fetch_images.py      скачивание и конвертация изображений
tools/build_data.py        пересборка data/content.js
```

## Как добавить коллекцию

1. Скачать изображения из подстраниц карточки Notion (Stories Rus / Stories Eng / Post Instagram Rus / Post Instagram Eng) через `tools/fetch_images.py`.
2. Положить `data/<slug>.json`.
3. `python3 -I tools/build_data.py`, закоммитить и запушить.

Источник: база Caviar Base → Tasks, карточки «Пост и сторис …».
